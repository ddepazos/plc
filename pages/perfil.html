En Render, el navegador solicita el usuario demo y la contraseña facilitada por quien administra el proyecto. No uses la contraseña de tu correo ni de otra cuenta.

Cómo se protegen las operaciones

La demo conectada usa HTTPS. El servidor valida el destinatario ficticio, el importe y el saldo disponible antes de guardar un movimiento. Los reintentos de una misma solicitud conservan una clave para evitar duplicados.

En GitHub Pages, las operaciones se simulan y guardan solo en este navegador, sin usar la API. Si la API de la versión conectada no está disponible, se muestran datos de ejemplo de solo lectura y los formularios de operaciones quedan desactivados. Si una operación queda sin confirmar por un corte de conexión, revisa el historial antes de repetirla.

Las claves de conexión a la base de datos se configuran en el servidor y no se incluyen en esta página.

Privacidad y uso responsable

En GitHub Pages, los movimientos y las notas permanecen en este navegador hasta reiniciar la demo o borrar los datos del sitio; no se envían a Neon. Los movimientos de la demo conectada se guardan en la base de datos del proyecto y son visibles para otras personas con acceso a la demo. No introduzcas datos personales en las notas o formularios.

Usa únicamente destinatarios ficticios con el formato PLC-DEMO-DESTINO. Nunca introduzcas datos de tarjetas, números de cuentas bancarias reales, claves privadas ni frases de recuperación.

Contraseña y ayuda de acceso

La contraseña compartida la gestiona quien administra PLC. Esta página no permite cambiarla ni recuperarla. Si no puedes entrar, solicita acceso al administrador por el canal que utilices con él.

No publiques la contraseña en GitHub ni en comentarios. En equipos compartidos, evita guardarla y usa una ventana privada; al terminar, cierra todas las ventanas privadas.

Funciones todavía pendientes

No hay registro de cuentas individuales, recuperación de contraseña por correo, verificación en dos pasos ni una lista de dispositivos con cierre de sesión remoto.

Esta pantalla informa sobre la protección actual; no activa esas funciones. La demo está destinada a probar la experiencia con datos ficticios.
